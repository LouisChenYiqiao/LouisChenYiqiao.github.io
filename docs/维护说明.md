## 三、如何更新内容

### 1. 修改文字

直接编辑 `index.html`，找到对应区块修改即可。例如联系方式区块：

```html
<section class="section" id="contact">
  ...
</section>
```

### 2. 更换图片

将新图片放入 `assets/images/`，然后在 `index.html` 或 `assets/css/style.css` 中修改引用路径。

常用图片位置：

- **首屏背景图**：定义在 `assets/css/style.css` 的 `.hero-bg` 规则中（当前为 `url("../images/20230312213234.jpeg")`）。
- **站点图标 favicon**：`assets/images/favicon.svg`。

### 3. 调整样式

全站唯一样式表为 `assets/css/style.css`，通过 CSS 变量（`:root` 中的 `--primary`、`--text` 等）控制配色与尺寸。

## 五、发布 / 部署

网站由 GitHub Pages 托管，源分支为 `main`。只要代码推送到 `main` 分支，GitHub 会自动重新构建发布。

```bash
git add -A
git commit -m "更新内容"
git push origin main
```

也可以使用封装好的部署脚本（自动读取本地凭据并推送）：

```bash
./scripts/deploy.sh "更新内容说明"
```

## 六、凭据（PAT）管理

为保证推送到 GitHub 所需的凭据既能被脚本统一调用、又不会被误上传，采用如下方案：

### 存放位置

凭据文件放在 **Agent 工作区根目录的 `secrets/` 目录下**，与仓库目录平行：

```
Agent/
├── LouisChenYiqiao.github.io/   # 仓库目录（会被推送）
└── secrets/
    └── github.token            # 凭据文件（在仓库之外，永不推送）
```

- 文件权限为 `600`（仅本人可读）。
- 该目录与文件已被 `.gitignore` 排除（`secrets/`、`*.token` 等规则），**不会被提交到 GitHub**。

### 使用方式

1. 将 GitHub Personal Access Token（需 `repo` 权限）写入：

   ```bash
   echo "你的PAT" > ../secrets/github.token
   chmod 600 ../secrets/github.token
   ```

2. 之后日常更新，直接运行：

   ```bash
   ./scripts/deploy.sh "本次更新说明"
   ```

   脚本会自动从 `../secrets/github.token` 读取凭据完成 fetch + commit + push，无需手动输入。

### 安全建议

- PAT 只保存在本机 `secrets/` 目录，不出现在任何 git 提交、配置或文档中。
- 如担心泄露，可随时在 GitHub 撤销并重新生成，再更新 `secrets/github.token`。
- 不要将 `github.token` 上传到任何公开仓库。

## 七、常见问题排查

### Q1：网站返回 404（"Site not found" 页面）

**根因**：GitHub Pages 未启用，或仓库名与用户名不匹配。

**排查步骤**：

1. 确认仓库名为 `用户名.github.io`（此处 `LouisChenYiqiao`）。
2. 进入仓库 **Settings → Pages → Build and deployment**，将 Source 设为 **Deploy from a branch**，分支选 **main**，目录选 **/ (root)**，保存。
3. 确认仓库内有 `index.html` 文件。
4. 等待几分钟后访问 `https://louischenyiqiao.github.io`。

> 注：GitHub Pages 的 URL 主机名会自动小写，所以访问 `https://louischenyiqiao.github.io` 即可（对应账号 `LouisChenYiqiao`）。

### Q2：修改后线上没变化

- 确认已 `git push` 到 `main` 分支。
- GitHub Pages 重新构建可能需要 1~2 分钟，稍等后刷新。
- 可用无痕窗口访问，避免浏览器缓存。

### Q3：图片不显示

- 确认图片路径大小写与文件名完全一致（GitHub Pages 路径大小写敏感）。
- 确认图片已提交到仓库。
